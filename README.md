# Eventos Ya
## Descripción del proyecto
Venta de boletos para diferentes tipos de eventos como conciertos, deportes y obras de teatro.
Hemos creado este sistema para que los usuarios puedan registrarse, iniciar sesion, explorar los diferentes eventos
disponibles, consultar fechas, lugares y precios, seleccionar boletos y poder realizar la compra. Cuando finalicen tendran
uno o varios boletos digital con codigo QR para ingresar al evento.
Tambien hemos incluido un panel para administración que permite gestionar los eventos, consultar ventas y llevar un mejor control de 
los boletos vendidos.
El objetivo es ofrecer una plataforma sencilla, organizada y facil de utilizar, tanto desde la computadora o de un celular.
